# Lexical-Analyzer
Lexical Analyzer in C for tokenizing source code into keywords, identifiers, operators, and special symbols.


A C-based Lexical Analyzer that performs the first phase of compiler design by scanning source code and identifying tokens such as keywords, identifiers, operators, constants, delimiters, and special symbols.

## Features

* Identifies C language keywords
* Detects valid identifiers
* Recognizes operators and delimiters
* Classifies numeric constants and literals
* Handles special symbols
* Ignores whitespace and unnecessary characters

## Technologies Used

* C Programming
* Standard C Libraries

## Project Structure

* Source code for lexical analysis
* Token classification logic
* Input source code processing

## How It Works

1. Reads the source code file or user input.
2. Scans the input character by character.
3. Identifies and classifies tokens.
4. Displays each token along with its corresponding category.
